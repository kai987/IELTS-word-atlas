# Qwen 日文复核流程 v5

2026-10-26（日本时间）。本次修改本地翻译工具；现有 7,298 条正式日文词库继续保留。

## 解决的问题

旧流程的 `col.N` 字段没有明确区分“补丁中的日译”与“程序保留的英文”，Qwen 因而把正确日文搭配改回英文。部分 tip 只保留英文术语、删除日文说明，仍能通过原来的结构检查。初译编号解析失败后，复核输入还会从字段映射变成原始文本分组，让复核兼任结构恢复，产生整条源文回填。

这些退化多数来自旧复核候选，其中很多模型已自评拒绝；不表示正式词库已被覆盖。

## 当前接收规则

1. 输入始终为逐字段 `{path, sourceLanguage, sourceText, draftJapanese}`。有英文的义项、例句和搭配从英文译日；只有中文的说明从中文译日。缺失、错型或未对齐的草稿在模型调用前进入待修复，原始输出保留作诊断。
2. Qwen 只修可证明的实质错误，不做文风润色、同义替换或新增读音。补丁必须包含 `path`、与原译文逐字一致的 `before`、日文 `text`、错误类型 `reason`、来自该字段源文的原文引句 `evidence`。`col.N` 只返回日译，英文部分由程序添加。
3. 程序逐字段拒绝英文/中文回填、混入明显非目标文字、占位符、重复路径、未知字段、原值或证据不匹配、术语/IPA 出现次数丢失，以及把原本保留的阿拉伯数字改掉等情况。短汉字词义、数字词义和提示中必需的英文术语可以保留。对实义英语词残留等疑点采用待复核，而不是宣称一定译错。
4. 被拒绝的字段保留初译；同一响应中可接受的修正仍可作为候选保存。只要有拒绝补丁、最终字段警告、未决问题或模型未批准，整条均为 `needsReview`。保留原译不是自动通过。通过机器门禁仅标记 `machineEligible`，所有候选仍为 `needsSemanticReview`。
5. 即便没有补丁，也检查所有保留字段。候选分块组装前再次确认代码版本、模型摘要、源文摘要和复核状态，阻止旧缓存混入。候选只写缓存旁的 `candidate-chunks/`，工具拒绝把缓存放在 `data/` 或 `public/`。独立源文复核后才能另行采用；模型不会自动改正式词库。

这些是保守的自动门禁。合法专名、引用或数字改写可能被 HOLD；全汉字中日同形词及纯日文语义退化也可能漏检。`evidence` 是可追溯的源文引句，不是语义正确的证明。正式采用仍需依据源文复评。

## 验证和重放

无需模型的回归测试：

```sh
npm run test:ja-review
```

新重放工具使用旧实验冻结的初译，不重新初译、不覆盖历史记录，也不写正式词库。默认选取 13 个有语言回退、结构失败、有效修复和语义退化风险的词条；它们是针对性回归样本，不代表完整 100 词或全库准确率。

```sh
# 仅对旧输出运行新门禁，无模型调用。
python3 scripts/atlas/benchmark-ja-review.py --offline --artifacts .local/ja-review-v5-offline

# 使用已安装的 Qwen Q8 重新复核同一批初译。
python3 scripts/atlas/benchmark-ja-review.py --live --artifacts .local/ja-review-v5-live
```

每次实验冻结代码、输入、模型摘要、参数、实际请求和原始响应；中断或失败保留记录，不自动重试挑结果。协议或代码变化必须换新目录。未对齐草稿单列 `held-draft`，不计为成功译文。`summary.json` 的语言门禁数与模型批准数都不等于实质错误数。

旧 Q4/Q8 对照固定使用归档 `translate-ja-local-v4.py`（SHA-256：`90da9704bc9e23b7ed5791cdea3f5e5262de3ca3224aaf58d6489c445fcd861a`），原始报告及其错误数不因本次修改而重算。当前可用的本地模型是 Q8 版本，本次不会下载已删除的 Q4 模型。

## 本次实测结果

使用 `qwen3.5:9b-q8_0` 复核默认 13 个针对性案例。11 条可对齐草稿实际发出 11 次请求，合计约 105 秒；2 条因草稿未对齐在调用前 HOLD。没有重新生成初译、重试挑选结果或写入正式词库。

对同一组可对齐的 11 条、92 个字段，按原实验实质错误准则另行进行源文复评，每字段最多计一个错误：

| 候选 | 实质错误字段 |
| --- | ---: |
| 原 Q8 初译 | 18 |
| 原 Q8 复核 | 29 |
| 新 v5 复核 | 16 |

新复核提出 7 个补丁，4 个通过程序补丁门禁、3 个拒绝。通过的 4 个中，独立语义复评确认 2 个有效修复（`probable.tip` 的禁止用法、`sister.col.2` 的年龄限定），另 2 个仍然译错。没有原本正确的字段新变错，但 `sister` 的两个原错误义项被改成另一种、更严重的错误；错误字段总数下降不能掩盖这两处退化。

11 个新候选未新增英文或中文回填；原草稿 `stripes.tip` 已有的中文残留仍被保留并明确 HOLD。5 条获得模型及语言门禁批准，其中 4 条仍有语义错误，特别是 `o-clock` 的上午/下午、九点与九点以后等问题。因此最终工具取消自动写入正式词库，统一留存候选，等待独立源文语义复核。

这是针对性、非盲的 Codex 回归复评，不是专业人工认证，也不代表完整 100 词或全库准确率。原始记录、冻结请求、补丁及独立语义标注位于 `.local/ja-review-v5-2026-10-26/`，包含 `semantic-review.json`。该试验冻结 worker SHA-256 为 `981747be77576412251800b65217c7ab78c88b9443d032002fe19bddc68d4f90`；试验后仅调整缓存/候选输出和禁止自动发布行为，复核提示词、补丁合并和字段门禁与冻结版本一致。

离线回归测试 36 项通过；网站原有 25 项测试通过；正式日文词库全量校验覆盖 7,298 条、67,649 字段，0 错误、0 语言警告。测试数量不代表译文语义零错误。
