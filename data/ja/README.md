对现有正式译文进行全库逐条语义复审，请使用独立入口 [正式日文语义复审流程](../../docs/ja-semantic-review.md)。它冻结最终网页版本，逐字段检错、暂存修正与独立裁决，不会重新初译后替换复审对象。

`entries/N.json` 与 `public/atlas/entries/N.json` 逐条对应，保留原有词条 ID、顺序和数组长度。翻译规则：有英文和中文对应的词义、例句、搭配，以英文为主译成日文；只有中文的提示、备注等做中译日。中文可辅助确认英文的含义，但不得覆盖英文或添加与英文冲突的事实。

日文翻译结合完整词条语境逐条生成或编写，保留英文词头、英文例句、搭配英文部分和提示中的英文表达及音标。

每条包含 `id`、`senses`（各义项日文）、`ex`（各例句日文译文）、`col`（原英文搭配＋`｜`＋日文）、`tip`、`note`。`fam`、`syn`、`ant` 通常是英文，原样保留；少量包含中文的项目通过同名可选数组翻译，英文项目仍保持原文。强制源文规则：有英文的词义、例句、搭配一律以英文为主翻译日文，中文仅辅助消歧，不得覆盖英文事实；仅有中文的 tip/note 从中文翻译。数量、否定、时间、关系、语法条件必须忠实于相应权威源文，不得使用占位符或省略内容。

组装命令：

```sh
python3 scripts/atlas/translate_ja.py
node scripts/check-japanese.mjs
```

组装器仅在所有词条均有完整翻译时写入 `public/atlas/ja/`；先应用 `scripts/atlas/ja-field-reviewed-*.json` 的逐字段修订，再应用 `ja-reviewed-*.json` 的整条修订。英文学习材料与音频保持不变。输出记录全部原始分块的 SHA-256，以检测源文更新后译文过期的情况。

可选本地批处理：在 Ollama 准备 `translategemma:12b-it-q8_0` 和 `qwen3.5:9b-q8_0`，运行 `python3 scripts/atlas/translate-ja-local.py`。v5 复核将源文与日文草稿逐字段配对，只接收附原译文和源文证据的错误修正；语言回退、术语丢失、无法对齐的草稿等进入待复核。被拒补丁保留原译，不会因此自动通过。检查点位于 `.local/ja-local-v5/`，记录代码、源文及模型摘要，候选分块组装再次检查来源。本地工具只向忽略目录暂存候选，不自动写入本目录；模型和程序门禁批准仍须独立源文语义复核后才能采用。详见 [v5 复核说明](../../docs/ja-review-v5.md)。
